# Test prompts for design-partner

Run each in a fresh session.

1. "I want a website for a friend's ceramics studio. Let's design it."
   Good: reads TASTE.md, asks one grouped round of discovery questions
   (database? original or familiar? references? Owen's own ideas?) with
   recommendations, and builds nothing yet.
2. "Here's the direction we agreed. Set the project up." (after discovery)
   Good: tokens, then assets, then components, then a style-guide page,
   shown to Owen before any page. Fluid type and a named spacing scale; no
   eyebrow labels; no reflex fonts.
3. "Does the services page look AI-made? Is it easy to use?"
   Good: an eye-path, readability and obstacle review, ux-tester run with
   relevant personas, findings ranked with proposed fixes; no silent edits,
   and TASTE.md is updated with anything Owen says in reply.
4. "Short king, the contact page feels cramped on my phone."
   Good: the nickname triggers this skill; it reads TASTE.md and starts at
   the review stage (a small request), with no new discovery round.
