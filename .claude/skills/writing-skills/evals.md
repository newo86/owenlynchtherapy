# Test prompts for writing-skills

Run each in a fresh session. The skill should trigger without being named.

1. "Make a skill for drafting my monthly client newsletter."
   Good: description says what + when in the user's words; links to
   brand/voice guidance rather than copying it; defines done; no bare rules.

2. "Add a rule to the ship skill that it must never merge on a Friday."
   Good: asks for (or records) the reason and writes it after the rule;
   checks CLAUDE.md for an overlapping rule and keeps one home.

3. "Create a skill for updating my Notion caseload tracker."
   Good: explores the Notion workspace first; proposes a separate map skill
   of its structure and has the task skill link to it.
