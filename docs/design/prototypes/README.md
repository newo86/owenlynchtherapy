# Sage Diary prototypes (Nov 2026)

Owen's approved direction for the dashboard ("I love this"). Clickable, with
example data only (fictional clients). Open either file in a browser.

- `sage-diary-phone.html`: phone. Tab bar Today, Calendar, Clients, More;
  swipe a client left for Move / Forms / Paid / Delete, which opens a
  full-screen page; More holds Money, Forms, Waitlist, Settings (Hours inside
  Settings); each client has a page with progress, sessions and payments.
- `sage-diary-desktop.html`: desktop. Sage rail with every section, two-column
  Today, hover actions on a client, a session panel on the right.

Look: website sage `#4F8A68` header band with a soft wave and the split circle
(powder blue, af Klint yellow, cream, dark), light sage page, soft yellow
`#F6CB52` for the one main button per screen, deep sage `#2F5A44` nav. Nav
items turn yellow on hover and when selected. Inter type.

Live copies (Owen's account): phone https://claude.ai/artifact/M9LswyeLicKV5pAxhhsRwq,
desktop https://claude.ai/artifact/VCtmEsVEFgzx8G7JNjTJ7V.

Hover on light rows and option tiles: a soft yellow row with a full-yellow icon square (text stays dark, since yellow text on light cards is unreadable).
